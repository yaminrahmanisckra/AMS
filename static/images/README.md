# Logo File Instructions

## For Remuneration Form Header

Please place the Khulna University logo file here with one of the following names:

- `KU logo 2.png` (preferred)
- `just_logo.png`
- `just_logo.jpg`
- `logo.png`
- `logo.jpg`
- `JUST_Logo.png`
- `JUST_logo.png`

The logo should be:
- PNG or JPG format
- Transparent background (preferred for PNG)
- Reasonable resolution (recommended: 200x200px to 400x400px)

The logo will automatically appear in the remuneration form header on the left side of the text.

**Important:** If the logo file is missing, the logo section will be automatically hidden.
